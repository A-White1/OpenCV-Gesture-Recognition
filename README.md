# OpenCV-Gesture-Recognition
A C++ OpenCV demo that has gesture recognition for a game of Rock, Paper, Scissors. Requires a webcam.

![FPS Gif](https://github.com/user-attachments/assets/aa2da03a-fef5-42a5-aa31-48b04b10e511)



Important:

Requires OpenCV, add the 'opencv_world480d.dll' file to the 'Application' folder. (Not included as the file is too large).

Run file "RockPaperScissorsProject in folder 'Application'".
